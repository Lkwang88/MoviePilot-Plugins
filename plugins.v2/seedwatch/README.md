# 小仓酱的种子监控助手（SeedWatch）

MoviePilot v2 插件：只读 MP 已有种子缓存，发现近期发布但可能漏订的剧集/电影，并对符合白名单的电影版本升级发出提醒。

- **核心场景**：补漏，不错过新剧集和新片发布
- **设计原则**：轻量、零额外站点请求；宁可漏报，不把查询失败当作“库内没有”
- **数据源**：`TorrentsChain().get_torrents()`

## 功能

1. **新剧集 / 新电影**：种子首次出现、在发布窗口内、媒体库不存在且下载历史无记录时提醒。
2. **电影洗版**：仅比较三档白名单：`4K UHD REMUX > 1080p REMUX > 4K WEB-DL`；同档 `P8（DV+HDR） > DV > HDR`。新种必须严格更高才通知。
3. **人工核对**：库内确认已有电影，但取不到版本路径时，将合格的新版本候选放入人工核对；`ISO`、`DIY` 不提醒。
4. **同作品聚合**：多个站点/种子合并成一行，显示种子数、站点、体积或体积范围。
5. **分类合并通知**：保留“新剧集 / 新电影 / 洗版候选 / 人工核对”分区；总作品数和字符数未超限时合并在一条消息中，超限自动拆分且不漏项。
6. **安全查重**：空标题、无媒体信息、分类冲突或媒体库查询异常时保守跳过；不会把异常当作“库内不存在”。
7. **调试心跳**：可查看缓存数、新签名、已见、超窗口、非影视和命中总数；有变化时才附变化站点和最多 3 个过滤样本。

## 判定规则

```text
候选 = 首次看到 + 发布年龄 ≤ 窗口
新内容通知 = 候选 + 媒体库确认不存在 + 下载历史无记录
洗版通知 = 候选电影 + 媒体库已存在 + 新版本评分严格高于库内版本
```

- 剧集不做版本升级比较。
- 签名为 `title + description + enclosure`，保存在插件数据中，重启不重复提醒。
- 清空已见记录后，缓存中仍在发布窗口内的种子会被重新判断。

## 配置

| 配置 | 默认 | 说明 |
|---|---:|---|
| 启用插件 | 关 | 启用后立即扫描，并按间隔继续扫描 |
| 扫描间隔 | 20 分钟 | 定时扫描周期 |
| 发布窗口 | 120 分钟 | 首次看到时允许进入判断的最大年龄 |
| 站点白名单 | 空 | 逗号分隔域名；空表示全部缓存站点 |
| 单条通知上限 | 10 条 | 按总作品数计，范围 1～50；超出自动拆分 |
| 新剧集 / 新电影 / 电影洗版 | 开 | 三类通知独立开关 |
| 排除已下载 | 开 | 根据下载历史排除 |
| 调试日志 | 关 | 输出短心跳；有变化或诊断信息时补充汇总 |
| 立即扫描一次 | 关 | 一次性开关，保存后执行并自动复位 |
| 清空已见记录 | 关 | 一次性开关，同时清通知历史/待处理数据 |

## 版本线

- **v0.1.9**：通知大改版——发布时间简化为 `X分钟前`；电影/洗版/人工核对行增加画质标签（`4K REMUX`、`4K WEB-DL`、`4K HDR` 等）；TG 富文本美化（分类标题加粗、画质等宽高亮，`parse_mode=HTML` 自动转义）；洗版对比优先使用下载历史最新种子的标题判断库内版本，无历史记录回退 strm 路径。
- **v0.1.8**：修复空识别信息导致的 MP 正则刷屏和 `media_exists` 报错；查询异常保守跳过；压缩 DEBUG；混合分类合并通知；修复同显示体积的假范围。
- **v0.1.7**：新增调试日志开关。
- **v0.1.6**：洗版改为真实版本比较，并增加人工核对。
- **v0.1.5**：同作品合并、分类排版、多消息完整发送、中文副标题兜底。
- **v0.1.0～v0.1.4**：首版及 MoviePilot v2 兼容、版本更新、已见记录修复。

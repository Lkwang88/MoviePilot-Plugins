# 小仓酱的种子监控助手（SeedWatch）

MoviePilot v2 插件：读取 MP 种子缓存，发现「新发布且媒体库/下载历史没有」的影视资源，通过 MP 通知通道提醒。

- **核心场景**：不错过新剧集发布（漏订/新剧）
- **设计原则**：轻量、低负担、补漏。允许漏报，不允许打扰
- **数据源**：`TorrentsChain().get_torrents()`（MP 订阅刷新抓取后落盘的缓存，**零额外站点请求**）

## 功能

1. **新剧集通知**：缓存里首次看到 + 发布 ≤120分钟 + 媒体库没有 → 提醒"新剧集（未订阅或漏订）"
2. **新电影通知**：同上，电影
3. **电影洗版通知**：库内已有旧版 + 新种带 DV+HDR / DV / HDR / 4K → 提醒"库内有旧版，新种更好"
4. **聚合通知**：一次运行命中合并成一条（默认最多 10 条，超出进待处理队列）
5. **排除已下载**：下载历史有记录 → 跳过（防"订阅自动下载中"误报）

## 判定规则

```
通知 = 新种子（首次看到 + 发布≤窗口） + 媒体库没有 + 下载历史没有
```

- 订阅状态**不参与判定**，只影响文案（有订阅=漏订提醒，无订阅=新剧发现）
- 剧集不洗版（只做"库里有没有"）
- 幂等：签名 = title+description+enclosure，插件自己记已见集合（plugindata），重启不重发

## 配置

| 配置 | 默认 | 说明 |
|---|---|---|
| 启用插件 | 关 | 总开关 |
| 扫描间隔 | 20 分钟 | 自定时 |
| 发布窗口 | 120 分钟 | 首次看到时判定 |
| 站点白名单 | 空=全部 | 逗号分隔域名 |
| 新剧集通知 | 开 | 核心场景 |
| 新电影通知 | 开 | |
| 电影洗版通知 | 开 | DV/HDR/4K 才发 |
| 洗版体积提升阈值 | 20% | v1 暂未启用（库内画质不解析） |
| 单条通知上限 | 10 条 | 1~50 |
| 排除已下载 | 开 | 下载历史查重 |

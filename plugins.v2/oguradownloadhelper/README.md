# 小仓酱的下载助手（OguraDownloadHelper）

MoviePilot V2 插件：**手动下载去重守护**。综合「下载历史 / 整理历史 / 媒体服务器同步」三类数据，对手动下载进行去重判定，防止重复下载。

## 功能

- 🛡️ **手动下载拦截**：已下载/已入库/媒体库已存在的媒体，再次手动下载时直接拦截并通知
- 🎬 **剧集粒度判定**：已下 S01 下载 S02 放行；已下 E1-12 再下 E1-12 拦截；部分重叠（E1-12 + E13-24）提示
- 📊 **洗版对比提示**：展示旧种子名、旧体积 vs 新体积，辅助判断是否为同一文件
- 🤖 **独立 TG Bot 交互**：拦截通知带「继续下载 / 取消」按钮，一键放行（可配置独立 bot token，噪音隔离）
- 🔓 **一次性放行**：放行后需重新发起下载，放行记录自动消费，防呆
- 🔒 **订阅/RSS 不受影响**：仅拦截手动下载，自动下载场景保持原生行为

## 工作方式

```
手动下载 → 资源下载事件（ResourceDownload）
    ├─ 命中放行标记 → 直接放行
    ├─ 去重判定命中 → 拦截（cancel）+ 记录 + 通知（TG按钮 / MP通道）
    └─ 未命中 → 正常下载
```

判定数据源（优先级）：
1. **整理入库记录**（TransferHistory，成功状态）
2. **媒体服务器同步**（MediaServerItem，含季集信息）
3. **下载历史**（DownloadHistory）

匹配键：媒体身份（TMDB/豆瓣/Bangumi/AniList ID）→ 标题+年份 → 标题模糊（仅提示）。

## 安装配置

1. 插件市场安装「小仓酱的下载助手」
2. 启用插件
3. 可选配置：
   - **独立 TG Bot Token**：在 [@BotFather](https://t.me/BotFather) 创建 bot 获取 token。配置后拦截通知走独立 bot（噪音隔离），按钮可操作放行
   - **TG 聊天 ID 白名单**：逗号分隔，仅这些聊天可操作按钮
   - 未配置 bot → 自动回退 MP 自带通知通道（通知含放行说明）

## 放行流程

拦截后选择「继续下载」→ 标记放行 → **重新发起下载**（再次点击下载按钮）→ 自动通过。

> 说明：拦截发生在 MP 添加下载任务之前，因此放行后需要重新发起一次下载；放行标记默认 24 小时有效（可配置），一次性使用。

## 远程命令

- `/ddg`：查看插件状态与统计
- `/ddg_bypass 媒体标题`：放行指定媒体的最近一次拦截

## 插件 API

- `GET /api/v1/plugin/OguraDownloadHelper/records`：拦截记录
- `GET /api/v1/plugin/OguraDownloadHelper/status`：状态统计
- `POST /api/v1/plugin/OguraDownloadHelper/bypass?token=xxx`：放行
- `POST /api/v1/plugin/OguraDownloadHelper/rebuild`：重建本地缓存

## 说明与限制

- **仅拦截手动下载**：订阅 / RSS 自动择优下载不受影响（原生判定已足够准确）
- **本地缓存**：SQLite 存储已知媒体指纹（启动全量导入 + 事件增量 + 每日 3 点自动重建），判定毫秒级
- **体积提示仅作参考**：解析依赖种子命名规范，差异 ≤5% 视为体积相近（可配置阈值）
- 拦截后 MP 前端会显示「添加下载任务失败」，这是拦截生效的正常表现，通知会说明原因
